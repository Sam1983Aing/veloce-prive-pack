Run it on your computer

You need Node.js. Then, in the folder:

npm install
npm run dev

Open the address it prints, ending in /veloce-prive-pack/. The pages are best on a laptop.

Add your own films

The films and the trailer aren't in the pack, so every wall shows a "Your film here" frame. Drop your MP4s into public/films and list them in films.json. The room films sheet has the prompts I used to make mine.
